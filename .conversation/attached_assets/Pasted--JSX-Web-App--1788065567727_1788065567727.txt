عايزك تحوّل ملف الـ JSX المرفق ده إلى تطبيق Web App شغال بشكل كامل، مع إمكانية استخدامه من الكمبيوتر والموبايل، **من غير ما تغيّر أي حاجة في محتوى التطبيق أو الـ UI أو النصوص أو الـ workflow الحالي**.

### المطلوب:

1. **تحويل ملف JSX إلى مشروع React كامل**

   * استخدم React + Vite أو أي setup مناسب.
   * الملف الحالي هو الـ component الأساسي للتطبيق.
   * لازم التطبيق يشتغل بشكل طبيعي على الكمبيوتر من خلال المتصفح.

2. **الحفاظ على التطبيق كما هو**

   * ممنوع تغيير التصميم أو الألوان أو النصوص أو أسماء الأقسام أو ترتيبها.
   * ممنوع تغيير طريقة إدخال الأدوار والأهداف والجدول والملاحظات.
   * ممنوع تغيير نظام مراجعة الأسبوع.
   * ممنوع تعديل الـ prompts أو طريقة صياغة تحليل الأهداف.
   * الهدف هو جعل التطبيق قابلًا للتشغيل والنشر فقط، وليس إعادة تصميمه أو تطوير محتواه.

3. **يكون Responsive**

   * نفس التطبيق لازم يشتغل بشكل مريح على:

     * Windows / Mac
     * Android
     * iPhone
   * الـ UI الحالي يفضل كما هو، مع معالجة أي مشاكل ضرورية فقط عشان يظهر بشكل صحيح على الشاشات الصغيرة.

4. **تحويله إلى PWA**

   * أقدر أفتح التطبيق من المتصفح على الكمبيوتر.
   * أقدر أفتحه من الموبايل.
   * أقدر أعمل Add to Home Screen / Install App على الموبايل.
   * يظهر كتطبيق مستقل بدون الحاجة لفتح المتصفح كل مرة.
   * إضافة manifest وservice worker والأيقونات المطلوبة بدون تغيير محتوى التطبيق.

5. **حفظ البيانات**
   التطبيق حاليًا يستخدم `window.storage` لحفظ بيانات الأسبوع.
   أريد استبدال/توفير implementation مناسب لهذا التخزين بحيث البيانات لا تضيع عند إغلاق التطبيق أو إعادة فتحه.

6. **المزامنة بين الأجهزة**
   أريد أن أقدر أستخدم نفس التطبيق من الكمبيوتر والموبايل، وتكون بياناتي متاحة على الجهازين.
   لذلك أحتاج نظام تخزين سحابي مناسب، مع الحفاظ على نفس الـ data structure والـ workflow الموجودين في التطبيق.

   لو احتاج الأمر تسجيل دخول، استخدم أبسط حل ممكن، ولا تضف أي features غير ضرورية.

7. **Claude API**
   التطبيق الحالي يستخدم Anthropic API لتحليل مراجعة الأسبوع.
   أريد الحفاظ على نفس الوظيفة والـ prompt والـ model الموجودين حاليًا.
   لكن **ممنوع وضع الـ API key مباشرة داخل الـ frontend**.
   استخدم backend/serverless function آمنة لاستدعاء Anthropic API.

8. **النشر**
   أريد المشروع يكون جاهزًا للنشر على خدمة مناسبة مثل Vercel/Netlify أو ما شابه، بحيث أحصل على URL واحد:

   `https://...`

   وأستخدم نفس الرابط من الكمبيوتر والموبايل.

9. **النتيجة النهائية**
   أريد تسليمي:

   * المشروع كامل.
   * جميع ملفات React/Vite.
   * إعدادات PWA.
   * إعدادات الـ backend/API.
   * إعدادات قاعدة البيانات/التخزين السحابي إن وجدت.
   * ملف `.env.example` يوضح الـ API keys المطلوبة بدون وضع أي secrets داخل المشروع.
   * خطوات التشغيل محليًا.
   * خطوات النشر.
   * خطوات تثبيت التطبيق على Android وiPhone.

### أهم شرط:

**لا تغيّر محتوى التطبيق الموجود في ملف JSX.**

أي تعديل يتم يجب أن يكون تقنيًا فقط لتشغيله، حفظ البيانات، المزامنة بين الأجهزة، حماية الـ API key، وتحويله إلى PWA.

الـ JSX المرفق هو الـ source of truth للتطبيق، وأريد الاحتفاظ بنفس الـ functionality والـ UI والـ text الموجود فيه.
